
# Exact-YOLO Dataset Sources

This repository provides the official sources of the five public datasets used in the Exact-YOLO study on aerial small object detection.

## Dataset Sources

1. **VisDrone2019-DET**  
   http://aiskyeye.com/

2. **AI-TOD**  
   https://github.com/jwwangchn/AI-TOD

3. **WAID**  
   https://github.com/xiaohuicui/WAID

4. **SeaDronesSee**  
   https://github.com/Ben93kie/SeaDronesSee

5. **SkySeaLand**  
   https://data.mendeley.com/datasets/d42n3cp86p/3

These datasets are publicly available and are maintained by their respective authors or hosting platforms. Please refer to the original sources for dataset access, terms of use, and citation requirements.
